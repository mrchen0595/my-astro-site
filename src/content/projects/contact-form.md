## 项目目标

这个项目条目用于把网站中的联系功能进一步整理成一个完整的独立案例。

除了表单界面本身，还需要理解用户输入、字段验证、提交状态、服务端处理以及错误反馈之间的关系。

## 计划整理的内容

后续会逐步把联系功能拆解成以下几个部分：

- 表单字段设计
- 客户端输入验证
- 服务端数据验证
- API 请求
- 成功状态反馈
- 错误状态反馈
- 防止无效提交
- 自动化测试

## 为什么值得单独整理

一个看起来很简单的联系表单，实际上同时涉及浏览器、客户端 JavaScript、服务端 API 和用户体验。

因此它非常适合作为学习前后端数据交互的案例。
