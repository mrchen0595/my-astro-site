## 项目目标

关于页面是网站开发过程中较早建立的独立页面之一。

它的主要目标是理解 Astro 的文件路由机制，并练习如何让不同页面共享统一的导航、布局和视觉风格。

## 我做了什么

创建独立的 `/about` 路由，并让页面使用网站统一的 Layout 和 Header。

页面内容与首页保持不同，同时继续共享网站全局的颜色、字体、间距和响应式规则。

## 关键功能

- 独立 `/about` 页面路由
- 公共 Header
- 公共 Layout
- 全局样式变量
- 响应式布局
- Light / Dark 主题兼容

## 遇到的问题

如果每个页面都独立编写导航、标题结构和公共样式，随着页面数量增加，会产生大量重复代码。

同时修改导航时，也需要分别修改多个页面。

## 如何解决

将公共页面结构拆分成可以复用的 Astro Components 和 Layout。

页面只负责自己的主要内容，而网站级结构由公共组件负责。

## 学到了什么

通过这个页面，我开始理解组件化并不是为了把所有 HTML 都拆成组件。

真正适合拆分的是：

- 多个页面重复出现的结构
- 有独立职责的 UI
- 需要统一维护的元素

这也是后续建立 Header、Footer、ProjectCard 等组件的基础。
